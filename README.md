## How it is built

A single `index.html` with inline CSS and no build step. GitHub Pages serves it from the `main` branch.

- Responsive layout for phone and desktop
- Light and dark mode, following the visitor's system setting
- Print-friendly styles

## Update the site

1. Edit `index.html`.
2. Preview it locally by opening the file in a browser, or run `python3 -m http.server 8000` and open <http://localhost:8000>.
3. Commit and push to `main`. GitHub Pages republishes in about a minute.
